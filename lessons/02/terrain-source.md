# Hawaiʻi Island topographic reference

The assignment reference is Andy Eskenazi's [Session 2 slides, p. 5](https://github.com/andyeske/How-to-CAD-Almost-Anything/blob/main/Session%20Files/Session%202/Session%202.pdf): the hooked northwestern coast, long southern cape, and separate Mauna Kea and Mauna Loa summits matter more to recognition than decorative cuts. The slide uses contours in feet. This study independently reconstructs the same island from a real elevation grid; it does not reproduce the original drawing or the instructor's model.

**Elevation data:** [Mapzen Terrain Tiles on AWS](https://registry.opendata.aws/terrain-tiles/), [Terrarium encoding](https://github.com/tilezen/joerd/blob/master/docs/formats.md), zoom 8, columns 16–17, rows 113–114. United States 3DEP (formerly NED) and global GMTED2010 and SRTM terrain data courtesy of the U.S. Geological Survey; global ETOPO1 terrain data: U.S. National Oceanic and Atmospheric Administration. See the distributor's [attribution and source terms](https://github.com/tilezen/joerd/blob/master/docs/attribution.md). These data have their own provenance; the project MIT license does not relicense source data.

[The cropped elevation grid](terrain-dem.png) stores nonnegative heights rounded to whole meters. Normal builds use this checked-in grid without network access. To refresh it, run `python terrain_input.py` in this directory; tile updates may change the result. [The reference image](terrain-reference.png) colors the **unsmoothed grid**, not the CAD output. The north-up crop has square Web Mercator pixels; the model maps each pixel to 0.4 mm in each horizontal direction. The 20 m perimeter is a near-coast proxy rather than a survey of the shoreline.

The model smooths the DEM slightly before taking contours; tiny isolated loops are omitted. It fits periodic splines at approximately three-pixel intervals and extrudes nine tiers of equal 1.5 mm thickness. Heights are ordinal and deliberately exaggerated, not true-scale vertical distances. Verification rasterizes horizontal sections from the reopened STEP, measures mask intersection/union against each unsmoothed reference band, and probes both named summits plus the saddle between them. The smallest summit regions are most sensitive to smoothing and pixel rounding. Neither the DEM nor these comparisons establish surveying accuracy.
