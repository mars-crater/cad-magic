# Repeated features
Choose what owns the spacing before choosing a pattern command. On a fixed wheel, count controls angle: place one complete feature at each angle i × 360° / count, excluding 360°. Build the seed in local radial, tangential and axial coordinates so its holes rotate with it. Revolve a section for an axisymmetric hub; mirror only around an actual symmetry plane.

On a wrapped lattice with fixed cell pitch, increasing circumferential count should grow the radius instead. Lay out the stagger on the sheet first. Identify shared corners modulo the circumference before instancing joints and rods; the final column joins the first, not a duplicate copy.

Reopen the nominal and edited exports. Check the features in each copy's local coordinates, the gap between copies, and the dimensions that must not move. For a periodic network check seam neighbors, edge duplication and open ends. Distinguish connected geometry from a single fused solid.
